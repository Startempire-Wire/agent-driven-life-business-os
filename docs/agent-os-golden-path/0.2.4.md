# Agent OS Golden Path 0.2.4

**Status:** candidate architecture correction  
**Date:** 2026-09-27  
**Parent:** 0.2.3 Portfolio Business Compiler

## Purpose

Correct the feedback/optimization architecture so W.I.N.S. is not a mandatory stage in ADLBOS.

The base loop exists for every Wirebot setup:

```text
observe source-owned outcomes + operating evidence
→ measure routine/system effect
→ synthesize private leverage/momentum
→ identify dominant constraint/opportunity
→ propose smallest leverage move
→ execute under current authority
→ verify effect
→ keep / improve / retire
→ reinvest released capacity
```

## Four Wirebot setup modes

```text
Wirebot Sovereign Operator
Wirebot Sovereign
Wirebot Direct
Wirebot Network
```

These are customer/setup modes, not numeric entitlement levels.

- **Sovereign Operator:** W.I.N.S. optional; explicit opt-in.
- **Sovereign:** W.I.N.S. optional; explicit opt-in.
- **Direct:** base loop always available; W.I.N.S. follows the Direct offer and does not imply Network membership/federation.
- **Network:** base loop always available; W.I.N.S. follows the Network participation policy.

For the top two setups, W.I.N.S.-off is a complete valid operating state.

## Ownership correction

- Source business/life systems and owner acceptance remain the outcome truth.
- Focusa owns governed work, Evidence and settlement.
- OpenClaw owns persistent Operating Partner runtime and default durable automations.
- UIAI owns browser/computer execution.
- Wirebot/Perpetua owns private cross-domain feedback/leverage synthesis and Quiet Kaizen.
- `operator.leverage_snapshot.v1` is a base private projection and requires no W.I.N.S.
- W.I.N.S. is an optional/setup-aware progression, recognition and community projection over that base truth.

## Regression intent

The valid base leverage fixture contains no W.I.N.S. refs. The regression suite separately verifies that an optional W.I.N.S. game projection can be layered onto the same leverage snapshot.

## Non-regression

This change does not remove W.I.N.S. capability. It prevents W.I.N.S. participation from being a prerequisite for analytics, momentum/leverage, optimization or a complete Sovereign operating loop.
