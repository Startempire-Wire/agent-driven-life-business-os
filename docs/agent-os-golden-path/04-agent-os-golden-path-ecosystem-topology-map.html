The Operating Partner works at owner altitude. A Workstream Foreman owns exact project/workstream responsibility. Workers and execution systems receive bounded assignments. Broad partner context is not copied into every worker merely because it may be useful.

4. Workforce creation versus workforce operation

Workforce Composer — Wirebot App

Determines what organization or role should exist, why, with what objective, capabilities, budget, supervisor and data access. It produces a proposed/approved assignment packet.

Focusa Workforce

Operates the active governed organization after Focusa has bound the role/work/authority. It shows Foremen, workers, active work, blockers, Needs You, evidence and execution posture.

life/business need -> Wirebot identifies capability gap -> Workforce Composer proposes role/assignment -> owner / CRIST / governance acceptance -> Focusa binds governed work and authority -> Focusa Workforce operates active work -> Evidence / settlement -> accepted outcome / W.I.N.S. -> optional MeriFolio standing

5. Operator Deployment

Operator Deployment is a commissioning/deployment profile, not another product, runtime tier or authority model.

Ownership / isolation

May use customer-owned/private infrastructure and Sovereign isolation where required.

Hosting / operation

Customer-owned, operator-managed, hosted or hybrid are independent choices.

Interfaces

Wirebot App, Focusa Workforce, Focusa Desktop, UIAI, voice and Veragensia are separate surfaces over owned domains.

Network

Private/off by default. Startempire federation is optional and explicit.

Packaging

Desktop/mobile packaging may use Tauri or another adapter later, but packaging technology never defines the product architecture.

Commercial layer

Licenses, implementation and support may be bundled commercially without collapsing entitlement into runtime authority.

6. Capability and authority

SUPPORTED != ENTITLED != ACTIVATED / CONNECTED != AUTHORIZED != CONSENTED FOR THIS EFFECT

Commercial entitlement can make a capability available. It does not silently grant a worker, partner, runtime, network participant or remote operator authority to use it.

7. Fleet versus federation

Fleet

Multiple machines, Agent Computers, daemons, browsers or execution bodies under one Operator/owner root. Every projection retains source environment and daemon identity.

Federation

Independent sovereign Operators exchange explicitly approved projections or requests. Federation never implies pooled memory, credentials, files, projects or inherited owner authority.

8. Evidence and closure

activity != Evidence candidate != verified Evidence != Focusa settlement / Receipt != accepted life/business outcome != portable standing

W.I.N.S. consumes accepted outcomes where applicable. MeriFolio may selectively project evidence-backed standing. Neither should infer success merely from activity, infrastructure readiness or a worker claiming completion.

10. Golden Path remains the deployment spine

Stage 0 Engage — owner, intent, authority, consent Stage 1 Workstation substrate — Pi/agents, Focusa, UIAI, secrets Stage 2 Operating Partner genesis — durable customer partner identity and workspace Stage 3 Cloud landing — VPS / execution substrate where applicable Stage 4 Mesh + identity — GitHub, Tailscale, machine/runtime identity Stage 5 Knowledge + audit — business knowledge, retrieval, system inventory Stage 6 Partner continuity — durable hosted/remote operation where applicable Stage 7 Operating plane — recurring work, workers, schedules, surfaces Stage 8 Ongoing operation — evidence, support, recovery, improvement

The sequence is reusable deployment doctrine, not a mandate that every customer use the same hosting topology, application packaging, network membership or support offer.

11. Diagnostic question

Given this owner’s goals and selected deployment posture, what capabilities and integrations are required, which are already working, which are blocked, and what is the smallest next implementation step that creates a real operating outcome?

The diagnostic reports applicable capability posture. It does not invent enrollment, a fleet registry, a new identity authority or a percentage that hides a critical blocker.
