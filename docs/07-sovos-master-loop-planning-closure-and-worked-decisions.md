## 4. Contention and bounded mathematical judgment

### 4.1 Recommended shared-resource decision rule

Use existing task/assignment/executor and temporal-priority owners, not a new scheduler or model priority store. Apply this order to currently eligible work:

1. Reject foreign/stale/unsupported/unpermitted work and preserve its disposition; no priority can override authority or privacy.
2. Retain incumbent accepted work and reconcile unknown/conflicting effects before another effect on the same subject/resource.
3. Honor current explicit owner purpose and supported committed temporal priority; show infeasible conflicts rather than claiming every window can be met.
4. Compare consequence/reversibility, authoritative remaining window and required dependency impact under the bound policy. Source uncertainty can justify investigation, not an invented emergency.
5. Within comparable permitted work, apply the existing executor's bounded fairness/minimum-share and aging policy. Reserve exception capacity only for the accepted exception class.
6. Preempt only at a supported safe checkpoint; a non-preemptible committed effect retains its reservation. Defer with an owner/coverage impact and next allocation, never silently drop.

Admission verifies child/shared caps and declared epoch. A forecast is not a reservation. Multiple domains cannot each spend the same shared allowance. Budget renewal or a recurring allocation comes from its actual owner policy, never from concern splitting or a fresh process.

### 4.2 A worked error-cost decision, not a confidence cutoff

Semantic question: **does this source-qualified language warrant an internal billing review?** This is not whether a ledger charge happened or a response is absent; those are source facts. Assume, solely for this worked example, an independently held-out/calibrated probability `p`. A model's output concentration is not automatically that probability.

Synthetic loss units are neither currency nor production policy. Internal review has fixed burden 1 plus false-alarm burden 4; postponing a material concern has miss cost 40. The two permitted choices have:

```text
L(review) = 1 + 4(1-p)
L(postpone) = 40p
review is lower-loss when p > 5/44
at p = 0.20: L(review) = 4.2, L(postpone) = 8
```

If owner-approved miss cost is 4 instead of 40, the threshold becomes `5/8`; at the same `p = 0.20`, postponing is lower-loss (`0.8` versus `4.2`). Consequence policy changes the decision even with the same model answer. These are hand-worked design examples, not benchmark results or universal thresholds.

The rule is applied only after source, route, freshness, current assignment, permitted options and budget checks. If the incumbent already performs that review, update the existing work under policy rather than dispatch another reviewer. If calibration is unavailable, report that and use a permitted deterministic review/abstention policy; do not fabricate `p`. A 0.99 model answer cannot authorize a refund, external disclosure or new appointment.

Calibration protocol: freeze consequence/option definitions and information sets; develop on separate cases; evaluate rules-only, optional model and warranted specialist on the same held-out scoped cases; report false alarms/misses, abstention, subgroup/language variation, burden, transport-inclusive latency and cost with uncertainty. Retain failed/censored cases. Select policy from permitted options and approved error costs, then version it through its owner; do not tune on receiver answers already visible to the decision maker.

### 7.2 A fully specified hypothetical TPM proposal

This proposal fixes the previously open toy transitions without claiming they implement business logic or IIT in software. Four binary units in order `C,A,R,V` stand for illustrative concern, attention, readiness and verification. Their names are analogies, not independent physical components. Define index `8C + 4A + 2R + V`; all sixteen states are allowed interventions, including impossible-looking operational combinations. One grain is one synchronous update; external background is empty for the full four-unit model.

```text
C' = A OR R
A' = C XOR V
R' = A AND (NOT V)
V' = C XOR R
T[x,y] = 1 if y = (C',A',R',V') from x; otherwise 0
```

| x → next x | x → next x | x → next x | x → next x |
|---|---|---|---|
| 0000 → 0000 | 0100 → 1010 | 1000 → 0101 | 1100 → 1111 |
| 0001 → 0100 | 0101 → 1100 | 1001 → 0001 | 1101 → 1001 |
| 0010 → 1001 | 0110 → 1011 | 1010 → 1100 | 1110 → 1110 |
| 0011 → 1101 | 0111 → 1101 | 1011 → 1000 | 1111 → 1000 |

Each next unit is deterministic conditional on x, so the state-to-state row factorizes into four unit conditional probabilities. Intervention priors are uniform over the perturbed units; reachability/frequency in an unperturbed trajectory is not the intervention prior.
