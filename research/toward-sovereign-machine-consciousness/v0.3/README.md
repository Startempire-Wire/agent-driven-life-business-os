# Toward Sovereign Machine Consciousness — Research Manuscript v0.3.1

**Status:** DRAFT research preprint and evaluation protocol, dated 22 November 2026. This is a new research publication artifact, **not** an amendment to SOVOS constitutional or product architecture.

The research question is whether persistent agentic systems with source-qualified feedback, goal-directed ad hoc operation, governed Workstreams, a truthful capability self-model, and evidence-linked outcomes perform better than controlled alternatives under equal resources and authority constraints. The work does not report measured results or establish subjective consciousness.

Contents:
- [Full paper](paper.md), intended for later typesetting and potential arXiv submission
- Four accessible vector diagrams in `figures/`: architecture ownership, progressive formalization, the cross-vertical embedded Focusa/UIAI substrate, and a proposed—not yet preregistered—ablation design matrix

**Evidence boundary:** the paper cites pin-revision public SOVOS/Focusa/UIAI sources and current issue contracts. Wirebot Core/App private design was source-reviewed but is not represented as publicly reproducible. The independent IIT 4.0 finite-model experiment is proposed, not computed. Its operational interaction quantity is not IIT's Phi.

**No software mutation:** this research contribution creates no new runtime, memory/authority store, scheduled operation, owner delegation, machine capability, model, or publication authority. Implementation is owned by the existing product repositories and approved contracts. Scientific publication decisions remain the author's.

## Cross-vertical research and benchmark handoff

The manuscript v0.3.1 adds a **portable Focusa + UIAI substrate** hypothesis across Wirebot, WorkRouter, Wirebase and Focusa Market Lab. Each application owns its own domain truth; reusable cognitive and interaction primitives are evaluated for continuity, correct authority, provenance and verified outcomes. A 24-hour monitored synthetic event workload is a proposed uptime experiment, distinct from simulated time and continuous LLM inference.

**Measured study owner:** [Focusa PR #731](https://github.com/Startempire-Wire/focusa/pull/731), extending public Spec 113/114 with the initial 18 live-task designs and a supplemental 12-case, four-domain design. No real benchmark results have been returned yet. Results should enter a separate implementation/evidence PR, including independent graders, model/arm/environment revisions, sample counts, failures, SHA-256 source artifacts and genuinely observed scientific charts.

**Book companion:** [The Entrepreneur's Path PR #104](https://github.com/Startempire-Wire/the-entrepreneurs-path/pull/104) freezes an author-review-only human-readable addendum and a source-corresponding scientific appendix. It does not authorize publication or revise existing released book assets.

**Source boundary:** WorkRouter, Wirebase, Market Lab and Wirebot Core/App software details were reviewed from author-accessible repositories but are private. Public scientific claims must rely on shareable reference adapters/fixtures or independently reviewable outcomes, never inaccessible source paths alone.
